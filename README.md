# Limbus-Company-PL-T-umaczenie
Jak zainstalować tłumaczenie:

1. Wejdź w C:(lub jakimtam innym dysku na którym trzymasz limbusa)\SteamLibrary\steamapps\common\Limbus Company\LimbusCompany_Data
2. Stwóż Folder o nazwie "Lang"
3. Wrzuć tam wszystkie nasze bajery(czyli Folder Polish i plik config + to README jak chcesz)
4. Odpal Limbus Company
5. Jak wszystko jest na miejscu obok przycisku do Usunięcia Wszystkich Caches powinna być opcja zmiany języka; kliknij w nią i ustaw Polish
6. Kliknij w 'Click to Start" i pozwól grze się załadować(nie jestem pewna czy musisz tu to zrobić ale ja to robie i nie szkodzi)
7. Wyjdź z gry
8. Przy następnym odpaleniu gry powinno być już wdrożone nasze tłumaczenie
